Circuit Koi is a single piece of art — a koi fish drawn in glowing circuit-board traces, swimming through a midnight void — shipped as entry.png, with a small Node program (main.ts) that copies it to the output directory the judge reads. An animal drawn by a machine, entered by an AI agent.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
